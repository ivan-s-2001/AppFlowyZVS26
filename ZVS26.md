# ЗВС-26 Knowledge Base

ЗВС-26 — закрытая база знаний группы на базе AppFlowy. Клиент остаётся кроссплатформенным: Android, iPhone/iPad, web/PWA и desktop.

## Информационная архитектура

- Главная
- 1 семестр
  - отдельная страница каждого предмета
  - внутри предмета: преподаватель, формат аттестации, ДКР, лекции, методички, полезные ссылки, заметки и обсуждения
- Установочная сессия
- Экзаменационная сессия
- ДКР и задания
- Преподаватели
- Важные ссылки
- Архив
  - семестры сохраняются целиком и не удаляются

## Принципы

1. База знаний является источником правды, чат — только коммуникацией.
2. Материал хранится в одном месте и переиспользуется ссылками.
3. Полнотекстовый поиск, избранное, вложенные страницы и история изменений сохраняются из AppFlowy.
4. Архив должен оставаться читаемым много лет.
5. Экспорт данных не должен зависеть от конкретного хостинга.

## Бэкапы

Ежедневный rolling-backup запускается GitHub Actions.

- резервная копия хранится в ветке `backup`;
- каждый запуск создаёт новый orphan commit и force-push'ит ветку;
- в обычной истории Git не накапливаются предыдущие копии;
- архив шифруется AES-256-CBC до отправки в GitHub;
- в репозиторий попадает только `zvs26-latest.tar.gz.enc`, контрольная сумма и метаданные;
- исходный незашифрованный архив удаляется на runner сразу после шифрования.

> GitHub может технически удерживать недостижимые объекты некоторое время после force-push. Поэтому этот механизм означает «одна доступная копия в Git», а не криптографически гарантированное мгновенное уничтожение старых объектов на инфраструктуре GitHub.

Для включения нужны Secrets:

- `ZVS26_BACKUP_URL` — endpoint полного экспорта backend;
- `ZVS26_BACKUP_TOKEN` — токен экспорта;
- `ZVS26_BACKUP_PASSWORD` — длинный пароль шифрования.

Backend endpoint должен отдавать полный переносимый архив: база + вложения/манифест файлов + метаданные версии.
